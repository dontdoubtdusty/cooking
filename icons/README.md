# Category and protein icons

Line icons from [IconOven](https://iconoven.com/icons) by Appic Marketing (MIT license),
taken from the `@iconify/json` package and recolored white so they sit on the colored tiles.

Which tile gets which icon is set in the `TICON` list in `index.html` (matched by words in
the category or protein name). To add one, drop a 24×24 white-stroke SVG in here and add
a line to that list. Tiles with no match keep their plain color.

`../img/globe.jpg` (the Cuisine tab's "All" tile) is rendered from NASA's Blue Marble
satellite imagery (public domain), via the texture shipped with the `three-globe` package.
